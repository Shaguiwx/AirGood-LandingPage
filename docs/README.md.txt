AirGood - Proyecto Web

AirGood es una página web creada para mostrar información sobre la calidad del aire en los distintos distritos de Lima. La plataforma permite visualizar zonas con mayor contaminación, consultar reportes y revisar alertas o recomendaciones básicas para el cuidado de la salud.

Organización de archivos:
- assets: imágenes, íconos y recursos multimedia utilizados en la web.
- css: hojas de estilo para el diseño de las páginas.
- js: archivos JavaScript con la lógica e interactividad.
- pages: vistas HTML del sitio (incluyendo index.html como pantalla principal).
- docs: Descripción breve del proyecto

Desarrollado por el Grupo 2 del curso de HCI.
